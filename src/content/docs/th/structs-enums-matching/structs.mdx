## การกำหนด Struct

Struct รวม field ที่เกี่ยวข้องกันไว้ภายใต้ประเภทชื่อเดียว แต่ละ field มีชื่อและ type ของตัวเอง

```rust
struct Point {
    x: f64,
    y: f64,
}

let p = Point { x: 3.0, y: 4.0 };
```

คุณสร้าง instance โดยระบุค่าสำหรับทุก field

## การเข้าถึง Field

เข้าถึง field ด้วย dot notation: `p.x`, `p.y` โดยค่าเริ่มต้น field จะ private ต่อ module นั้น ใส่ `pub` นำหน้าเพื่อเปิดให้เข้าถึงจากภายนอก

## Deriving Debug

คุณไม่สามารถ `println!("{}", p)` struct ได้ — ไม่มี format ที่มนุษย์อ่านได้เป็นค่าเริ่มต้น เพิ่ม `#[derive(Debug)]` เหนือ struct เพื่อเปิดใช้ format `{:?}` แทน ซึ่งเป็นสิ่งที่คุณใช้บ่อยระหว่างพัฒนา

```rust
fn main() {
    #[derive(Debug)]
    struct Point { x: i32, y: i32 }

    let p = Point { x: 1, y: 2 };
    println!("{:?}", p); // Point { x: 1, y: 2 }
}
```

## Struct Update Syntax

เมื่อต้องการ instance ใหม่ที่แชร์ field ส่วนใหญ่กับ instance ที่มีอยู่ ใช้ syntax `..` สำหรับ update:

```rust
struct Point {
    x: f64,
    y: f64,
}

let p = Point { x: 3.0, y: 4.0 };
let p2 = Point { x: 10.0, ..p };
```

โค้ดนี้คัดลอก field ที่เหลือ (`y` ในกรณีนี้) มาจาก `p` field ที่ implement `Copy` จะถูกคัดลอก ส่วน field ที่เป็น `Move`-only จะถูก **move ออกจาก** ต้นฉบับ

ประเด็นสุดท้ายนี้สำคัญ: ถ้า field ใดที่นำมาจาก `..base` ไม่ใช่ `Copy` แล้ว `base` จะกลายเป็น **partially moved** — คุณใช้ `base` ทั้งก้อนไม่ได้อีก (เช่น ใน debug print แบบ `{:?}`) แม้ว่า field ที่คุณไม่ได้เอาไปจะยังอยู่ก็ตาม

```rust
// @expect-error E0382
#[derive(Debug)]
struct Point {
    x: i32,
    name: String,
}

fn main() {
    let p1 = Point { x: 1, name: String::from("origin") };
    let p2 = Point { x: 10, ..p1 }; // p1.name is moved into p2

    println!("{:?}", p1); // ERROR: p1.name was moved out
    println!("{:?}", p2);
}
```

```text
error[E0382]: borrow of partially moved value: `p1`
  --> src/main.rs:12:22
   |
10 |     let p2 = Point { x: 10, ..p1 }; // p1.name is moved into p2
   |              --------------------- value partially moved here
11 |
12 |     println!("{:?}", p1); // ERROR: p1.name was moved out
   |                      ^^ value borrowed here after partial move
   |
   = note: partial move occurs because `p1.name` has type `String`, which does not implement the `Copy` trait
```

## Methods

เพิ่มพฤติกรรมให้ struct ในบล็อก `impl` แต่ละ method รับ receiver เป็น parameter แรก

<Callout title="Methods รับ self, &self หรือ &mut self">
- `self` — method รับความเป็นเจ้าของ instance นั้น (consume มัน)
- `&self` — method ยืม instance แบบ immutable อ่าน field ได้แต่แก้ไขไม่ได้
- `&mut self` — method ยืม instance แบบ mutable อ่านและแก้ไข field ได้

Method ส่วนใหญ่ใช้ `&self` (อ่านอย่างเดียว) หรือ `&mut self` (อ่าน-เขียน) ใช้ `self` เฉพาะเมื่อคุณตั้งใจจะ consume ค่านั้นจริงๆ เช่นใน builder pattern
</Callout>

```rust
struct Point {
    x: f64,
    y: f64,
}

impl Point {
    fn distance_from_origin(&self) -> f64 {
        (self.x * self.x + self.y * self.y).sqrt()
    }
}
```

## Associated Functions (รูปแบบ `new`)

ฟังก์ชันในบล็อก `impl` ที่**ไม่**รับ parameter `self` เรียกว่า *associated functions* เรียกใช้ด้วย syntax `::` ชื่อตามแบบแผนสำหรับ constructor คือ `new`:

```rust
struct Point {
    x: f64,
    y: f64,
}

impl Point {
    fn new(x: f64, y: f64) -> Self {
        Point { x, y }
    }
}

let p = Point::new(1.0, 2.0);
```

`Self` ภายในบล็อก `impl` คือ alias ของประเภทที่กำลัง implement

## Tuple Structs

Tuple struct ตั้งชื่อให้กับลำดับ field ที่ไม่มีชื่อ มีประโยชน์เป็น wrapper แบบ type-safe ที่เบา:

```rust
struct Color(u8, u8, u8);

let red = Color(255, 0, 0);
println!("{}", red.0); // access by index
```

ต่างจาก tuple ธรรมดา `Color` และ `Point` ที่มี field type เดียวกันคือคนละ type — คอมไพเลอร์จะปฏิเสธการนำมาปนกัน

export const structsCode = `#[derive(Debug)]
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    fn new(width: f64, height: f64) -> Self {
        Rectangle { width, height }
    }

    fn area(&self) -> f64 {
        self.width * self.height
    }

    fn perimeter(&self) -> f64 {
        2.0 * (self.width + self.height)
    }

    fn is_square(&self) -> bool {
        self.width == self.height
    }
}

struct Color(u8, u8, u8);

fn main() {
    let rect = Rectangle::new(5.0, 3.0);
    println!("Rectangle: {:?}", rect);
    println!("Area: {}", rect.area());
    println!("Perimeter: {}", rect.perimeter());
    println!("Is square: {}", rect.is_square());

    let square = Rectangle::new(4.0, 4.0);
    println!("Is square: {}", square.is_square());

    let red = Color(255, 0, 0);
    println!("Red: ({}, {}, {})", red.0, red.1, red.2);
}`;
