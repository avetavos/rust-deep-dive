## Generic Functions

แทนที่จะเขียน `largest_i32`, `largest_f64` และ `largest_char` แยกกันเป็นฟังก์ชันคนละตัว generics ให้คุณเขียนเพียงตัวเดียว:

```rust
fn largest<T: PartialOrd>(list: &[T]) -> &T {
    let mut biggest = &list[0];
    for item in list {
        if item > biggest {
            biggest = item;
        }
    }
    biggest
}
```

ส่วน `<T: PartialOrd>` ประกาศ **type parameter** ชื่อ `T` พร้อม **trait bound** trait bound `PartialOrd` หมายความว่า "ฟังก์ชันนี้รับ type ใดก็ได้ที่รองรับ operator `>` และ `<`" ถ้าไม่มี bound นี้ compiler จะปฏิเสธการเปรียบเทียบ `item > biggest` เพราะไม่ใช่ทุก type ที่เปรียบเทียบกันได้

<Callout title="Generics ถูก monomorphize — zero runtime cost">
Compiler จะสร้าง copy เฉพาะของฟังก์ชันสำหรับแต่ละ concrete type ที่คุณใช้ — หนึ่งชุดสำหรับ `i32` หนึ่งชุดสำหรับ `char` และอื่นๆ กระบวนการนี้เรียกว่า monomorphization machine code ที่ได้เหมือนกับที่คุณเขียนมือแยกสำหรับแต่ละ type ทุกประการ ดังนั้น generics จึงไม่มี overhead ณ runtime
</Callout>

## Generic Structs

Struct ก็ทำเป็น parameterized ได้เช่นกัน `Pair<T>` เก็บค่าสอง type `T` เดียวกัน:

```rust
struct Pair<T> {
    first: T,
    second: T,
}
```

เมื่อคุณสร้าง instance compiler จะอนุมาน `T` จากค่าที่คุณให้:

```rust
struct Pair<T> {
    first: T,
    second: T,
}

let p = Pair { first: 5, second: 10 }; // T inferred as i32
```

## `impl` Blocks สำหรับ Generic Structs

การเพิ่ม method ให้ generic struct ต้องระบุ type parameter ซ้ำในบรรทัด `impl`:

```rust
struct Pair<T> {
    first: T,
    second: T,
}

impl<T: std::fmt::Display + PartialOrd> Pair<T> {
    fn larger(&self) -> &T {
        if self.first > self.second { &self.first } else { &self.second }
    }
}
```

ที่นี่ `T` ต้อง implement ทั้ง `Display` (สำหรับ printing) และ `PartialOrd` (สำหรับเปรียบเทียบ) คุณสามารถจำกัด method ให้แคบกว่าที่ struct เองต้องการได้ — `Pair<T>` มีอยู่ได้สำหรับ `T` ใดก็ตาม แต่ `larger` จะใช้ได้เฉพาะตอนที่ `T` เปรียบเทียบกันได้

## Trait Bounds และ `where` Clauses

Bound แบบ inline ใช้ได้ดีเมื่อมีข้อจำกัดแค่หนึ่งหรือสองอย่าง เมื่อ signature ยาวขึ้น `where` clause ช่วยให้อ่านง่ายขึ้น:

```rust
// Inline bounds
fn notify<T: Clone + std::fmt::Debug>(item: T) {
    println!("{:?}", item.clone());
}

// Equivalent where clause
fn notify_where<T>(item: T)
where
    T: Clone + std::fmt::Debug,
{
    println!("{:?}", item.clone());
}

fn main() {
    notify(1);
    notify_where("same bound, different syntax");
}
```

ทั้งสองรูปแบบเหมือนกันทุกประการสำหรับ compiler เลือกแบบที่ชัดเจนกว่า

## Multiple Type Parameters

คุณไม่ได้ถูกจำกัดให้มี type parameter เดียว ฟังก์ชันหนึ่งรับได้สองตัวหรือมากกว่า:

```rust
fn zip_display<A: std::fmt::Display, B: std::fmt::Display>(a: A, b: B) {
    println!("{} + {}", a, b);
}
```
